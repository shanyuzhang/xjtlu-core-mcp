开始之前

你需要准备

一台 Mac 或 Windows 电脑

不需要管理员密码，也不用改任何系统设置。

Chrome 或 Edge 浏览器

用来登录学校账号。没有的话先装一个 Chrome。

一个电脑版 AI 应用

推荐 Claude 桌面版，也支持 Codex、Cursor、Windsurf。网页版聊天暂时连不上。

安全吗

你的账号，只在你的电脑上

密码只输在学校登录页

工具不会让你在别处输入密码，也不会保存密码。它只记住登录状态，就像浏览器的“保持登录”。

只看，不改

不会提交作业、开始测验、发帖或改成绩，也不会绕过任何人机验证。

资料留在你电脑上

登录状态和课件都只存在你自己的电脑。注意：你让 AI 读的内容，会发给你所用的 AI 服务。

常见问题

遇到问题？

在国内能打开这个网址吗？

网址通过 Cloudflare 和 GitHub Pages 提供，大多数网络能直接打开。安装时用到的 Node.js 和依赖都会在官方源太慢时自动换成国内镜像。如果网页或安装命令打不开，换个网络（校园网、手机热点）再试。

为什么不是 npm / npx 命令？

npx 命令要求电脑上已经装好 Node.js，而且要从 GitHub 和 npm 官方源下载，国内经常很慢。这一行命令在没有 Node.js 的电脑上也能用：它会自己装好 Node.js，遇到慢的下载源自动换国内镜像。已经装了 Node.js 的同学，它会直接用现有的。

登录过期了，或者 AI 说“需要重新登录”

再运行一次同一行安装命令（或者把上面那段话再发给 AI 一次）就行，会重新弹出登录窗口。Node.js 已经装好的话不会重复下载。

装好了，但 AI 里找不到我的课程

先把 AI 应用完全退出（Mac 上按 ⌘ + Q），再重新打开。还不行的话，再运行一次安装命令，最后问你要不要连接 AI 应用时按回车。

提示“没有找到 Claude 桌面版、Codex、Cursor 或 Windsurf”

先安装其中一个（推荐 Claude 桌面版），打开一次，再运行一次安装命令。

登录窗口一直白屏

关掉这个窗口，确认网络正常后再运行一次安装命令。工具用的是一个独立的浏览器窗口，和你平时用的 Chrome 互不影响。

下载很慢，或者提示下载失败

安装程序会自动换用国内镜像。仍然失败的话，换个网络（比如校园网或手机热点）再试一次。

它能做什么，不能做什么？

能查课程、作业和测验的时间与要求，能读讲义 PDF、Word，能把整门课的资料存到电脑。扫描版 PDF（图片）读不出文字；单个文件最大 60 MB；外部网站上的资料不会下载。

可以把这个网页发给同学吗？

可以。网页里没有任何人的账号信息，同学用自己的学校账号登录。但不要把你电脑上的 .xjtlu-session-mcp 文件夹发给别人，那里有你的登录状态。

怎么卸载？

删除用户目录下的 .xjtlu-session-mcp 文件夹即可；AI 应用的设置里会多一个叫 xjtlu-core 的连接，也可以一并删掉。下载的课件在「文稿 / XJTLU Core」，想留就留着。

给懂技术的同学

这是一个本地 stdio MCP 服务器，共 9 个只读工具（课程、作业/测验、活动、文件列表、读文件、批量保存、导出目录等），源码在 GitHub。安装命令会把 Node.js（官方二进制包，校验 SHA-256）和程序装进 ~/.xjtlu-session-mcp，再修改你同意的 AI 客户端配置，并保留备份。登录窗口是不受自动化控制的普通 Chrome / Edge。目前在 macOS 上实测通过；Windows 脚本按同样流程编写，尚未真机测试。
