GET CONNECTED

三步，连接你的课程。

01

下载并解压

点击上方下载按钮，解压 xjtlu-core-mcp.zip。
先安装 Node.js 和 Chrome / Edge，再运行工具。

02

运行安装向导

打开解压后的文件夹，双击 START-MAC.command。若系统不允许，打开终端，进入该文件夹后运行 bash START-MAC.command。

03

登录，然后重启 AI

按提示选择课件目录，在学校窗口完成登录。对要接入的 AI 应用输入 y，其余输入 n。完成后重启 AI 客户端。

安装器会先把代码和依赖放到你的用户目录。修改 AI 客户端配置前会询问并备份。HTML 本身不会执行程序、读取学校密码或修改电脑设置；需要你运行下载后的安装向导。

WHEN YOU NEED A HAND

使用时遇到问题？

安装后，AI 没有出现 Moodle 工具

先完全退出并重启 AI 客户端。安装时要对自己的客户端输入 y；如果没有检测到客户端，打开工具包中的 README-XJTLU.md，按「手动配置」操作。此工具需要支持本地 stdio MCP 的客户端，普通聊天网页不一定支持。

普通 Chrome 已登录，为什么 MCP 仍提示未登录？

它们是不同的会话。请在工具新开的 MCP 专用窗口里登录，不要在平时的 Chrome 或 AI 内置浏览器里重复登录。终端会显示当前阶段，出现「MCP 专用会话已保存」才完成连接。在该窗口点击 XJTLU Account，输入账号密码；回到 Learning Mall 后窗口会自动关闭。若认证页持续白屏、终端提示网关返回 HTTP 400，请更新到最新工具包后重新运行 login。

登录过期了，或想换成当前学年

macOS 在终端运行 node ~/.xjtlu-session-mcp/app/bin/xjtlu-cli.js login。Windows 在命令提示符运行 node "%USERPROFILE%\.xjtlu-session-mcp\app\bin\xjtlu-cli.js" login。学校地址默认是 AY25/26 归档站；切换站点的命令和限制见 README，不保证所有学年主题都兼容。

没有装 Node.js / npm 安装失败 / 学校打不开

从 nodejs.org 安装 Node.js LTS，并重新打开终端。如果依赖下载失败，检查能否访问 npm registry；如果学校站点打不开，先用普通浏览器打开归档站，检查网络或校园 VPN。无需关闭电脑的安全保护。

能做什么，暂时不能做什么？

可以读取可见的课程结构、作业与测验详情，并保存 PDF、文档等资料。PDF / DOCX / 文本可以提取文字；扫描 PDF 需要另外做 OCR。单个文件上限 60 MB。批量保存不会保证覆盖外部网站、论坛附件和所有嵌套活动。

工具不提供提交作业、开始测验或发帖能力。正常浏览可能产生学校访问日志或自动完成标记。请遵守学校和课程的 AI 使用要求。

我能把这个 HTML 发给同学吗？

可以。这份 HTML 内含通用程序包，没有任何人的学校登录状态或课件。直接把 HTML 文件发送给同学，同学用浏览器打开并下载工具包即可。不要分享你电脑上的 .xjtlu-session-mcp 文件夹。

如何卸载？

先在 AI 客户端删除名为 xjtlu-core 的 MCP 配置，或恢复安装向导保存的备份。关闭工具后，删除用户目录下的 .xjtlu-session-mcp 文件夹。下载的课件默认位于 Documents / XJTLU Core，可自行保留。

工具包校验与源代码

工具包包含可阅读的 JavaScript 源码、依赖锁文件、MIT 许可和文件摘要清单，无需信任不透明的二进制程序。基于 canvas-session-mcp 增加 Moodle 适配；该原始仓库尚不包含这份适配代码。
