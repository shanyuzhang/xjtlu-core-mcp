长期使用

装一次，以后直接说

装一次就够

以后每次打开 Codex、Claude Code 等 AI，课程助手都会在后台自动启动，不用再运行任何命令。

以后直接说

比如「西浦课程助手：我最近有哪些 DDL？」「把 MTH205 的课件下载到这个文件夹」。话里带上“西浦课程助手”或“Learning Mall”，AI 更容易想到用它。

登录过期了

直接说「帮我登录西浦课程助手」，电脑上会弹出学校登录窗口，登录完回来接着问就行，不用打开终端。

更新到新版本

再运行一次那行安装命令（或把「让 AI 帮我装」那段话再发一次），已经装好的部分不会重复下载。换了电脑或换了 AI 应用，也是在那边再装一次。

开始之前

你需要准备

一台 Mac 或 Windows 电脑

不需要管理员密码，也不用改任何系统设置。

Chrome 或 Edge 浏览器

用来登录学校账号。没有的话先装一个 Chrome。

一个电脑上的 AI 应用

比如 Codex、Claude Code、Kimi Code，也支持 Claude 桌面版、Cursor、Windsurf。网页版聊天暂时连不上。

安全吗

你的账号，只在你的电脑上

密码只输在学校登录页

工具不会让你在别处输入密码，也不会保存密码。它只记住登录状态，就像浏览器的“保持登录”。

只看，不改

不会提交作业、开始测验、发帖或改成绩，也不会绕过任何人机验证。

资料留在你电脑上

登录状态和课件都只存在你自己的电脑。注意：你让 AI 读的内容，会发给你所用的 AI 服务。

常见问题

遇到问题？

在国内能打开这个网址吗？

网址通过 Cloudflare 和 GitHub Pages 提供，大多数网络能直接打开。安装时用到的 Node.js 和依赖都会在官方源太慢时自动换成国内镜像。如果网页或安装命令打不开，换个网络（校园网、手机热点）再试。

能用 npm / npx 安装吗？

也可以用：已经装了 Node.js 的同学，运行 npx -y xjtlu-core-mcp@latest setup 就行。但很多同学电脑上没有 Node.js，那样连 npx 这个命令都没有，所以网页上主推的是一行安装命令：它会先自己装好 Node.js，再从 npm 的国内镜像下载课程助手。

登录过期了，或者 AI 说“需要重新登录”

直接对 AI 说「帮我登录西浦课程助手」，电脑上会弹出学校登录窗口，登录完回来继续问就行。也可以再运行一次网页上的安装命令。Node.js 已经装好的话不会重复下载。

装好了，但 AI 里找不到我的课程

先把 AI 应用完全退出（Mac 上按 ⌘ + Q），再重新打开。还不行的话，再运行一次安装命令，最后问你要不要连接 AI 应用时按回车。

提示“没有找到支持的 AI 应用”

先安装其中一个（比如 Codex、Claude Code 或 Kimi Code），打开一次，再运行一次安装命令。

登录窗口一直白屏

关掉这个窗口，确认网络正常后再运行一次安装命令。工具用的是一个独立的浏览器窗口，和你平时用的 Chrome 互不影响。

下载很慢，或者提示下载失败

安装程序会自动换用国内镜像。仍然失败的话，换个网络（比如校园网或手机热点）再试一次。

它能做什么，不能做什么？

能查课程、作业和测验的时间与要求，能读讲义 PDF、Word，能把整门课的资料存到电脑。扫描版 PDF（图片）读不出文字；单个文件最大 200 MB；外部网站上的资料不会下载。

可以把这个网页发给同学吗？

可以。网页里没有任何人的账号信息，同学用自己的学校账号登录。但不要把你电脑上的 .xjtlu-session-mcp 文件夹发给别人，那里有你的登录状态。

下载的课件存在哪里？

如果你是在 Codex、Claude Code 等 AI 里打开了某个文件夹再让它下载，课件会直接存进这个文件夹（每门课一个子文件夹），AI 会先告诉你存到哪、完成后给出完整路径。想换地方，直接告诉它文件夹路径就行（需要在你自己的用户目录里）。没有指定时，存在「文稿 / XJTLU Core」。

怎么卸载？

删除用户目录下的 .xjtlu-session-mcp 文件夹即可；AI 应用的设置里会多一个叫 xjtlu-core 的连接，也可以一并删掉。下载的课件在「文稿 / XJTLU Core」，想留就留着。

给懂技术的同学

这是一个本地 stdio MCP 服务器，共 12 个工具（在对话里登录、课程、DDL 时间线、按课程从 handbook 和作业说明里找 DDL、作业/测验、活动、文件列表、读文件、批量保存、导出目录等），除保存文件外都只读，源码在 GitHub。安装命令会把 Node.js（官方二进制包，校验 SHA-256）和程序装进 ~/.xjtlu-session-mcp，再修改你同意的 AI 客户端配置，并保留备份。登录窗口是不受自动化控制的普通 Chrome / Edge。目前在 macOS 上实测通过；Windows 脚本按同样流程编写，尚未真机测试。
